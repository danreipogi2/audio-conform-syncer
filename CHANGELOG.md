# Changelog

All notable project changes will be documented here.

This project does not currently have a public release.

## 0.1.0 - Unreleased

- Created the initial Python package structure.
- Added the MVP CLI for extracting guide audio, matching clean source audio, and writing reports.
- Added JSON and Markdown report writers.
- Added report summaries, diagnostics, confidence labels, and score margins.
- Added `--min-score-margin` for filtering ambiguous repeated-audio matches.
- Added a local drag-and-drop sync app with automatic video/audio classification.
- Added synced MP4 export from matched clean audio and the reference video.
- Added timeline layer review data and UI for matched/unmatched audio sources.
- Added conservative Premiere and DaVinci Resolve XML export actions.
- Added normalized correlation, timeline merge, CLI, and generated demo workflow tests.
- Added project documentation for development, architecture, roadmap, contribution, and security.
